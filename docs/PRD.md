# PRD: Knowledge2Deck

## 목표
개인이 수집한 AI 리서치 페이퍼 아카이브(마크다운)를 검색·탐색 가능한 웹사이트로 공개한다.
리포에 논문을 추가하면(push) 사이트에 자동 반영된다.

## 사용자
- 1차: 본인 — 수집한 논문을 어디서든 빠르게 찾아보는 용도
- 2차: 동료 리서처 — 링크 공유로 논문 목록·초록을 열람

## 핵심 기능
1. 논문 목록 — 연도별/추가일순 브라우징, 카테고리(연도·tech-report) 필터
2. 논문 상세 — 제목·저자·초록·arXiv 링크, 슬라이드 존재 시 링크
3. 클라이언트 검색 — 제목·저자·초록 텍스트 검색 (빌드 타임 인덱스 생성)
4. GitHub 연동 — main push → Actions 빌드 → Pages 배포 자동화

## MVP 제외 사항
- 로그인·인증·개인화 (전부 공개 정적 페이지)
- 서버·DB·CMS 어드민 (리포의 MD 파일이 곧 CMS)
- 댓글·좋아요 등 소셜 기능
- PDF 뷰어 내장 (arXiv 원본 링크로 대체)
- TBD/, next-plan/ 등 작업용 디렉토리 노출

## 단계별 계획
- Phase 1 (현재): 콘텐츠 리포 정비 — 문서·규칙·파이프라인 안정화
- Phase 2: `site/` 스캐폴딩 — MD 파서 + 목록/상세 페이지 + 정적 export
- Phase 3: 검색·필터, GitHub Actions 배포 파이프라인
- Phase 4 (선택): 태그 체계, 논문 간 연관 링크, RSS
