[Hybrid Linear Attention Done Right: Efficient Distillation and Effective Architectures for Extremely Long Contexts](https://arxiv.org/abs/2601.22156)

Yingfa Chen, Zhen Leng Thai, Zihan Zhou, Zhu Zhang, Xingyu Shen, Shuo Wang, Chaojun Xiao, Xu Han, Zhiyuan Liu

> Hybrid Transformer architectures, which combine softmax attention blocks and recurrent neural networks (RNNs), have shown a desirable performance-throughput tradeoff for long-context modeling, but their adoption and studies are hindered by the prohibitive cost of large-scale pre-training from scratch. Some recent studies have shown that pre-trained softmax attention blocks can be converted into RNN blocks through parameter transfer and knowledge distillation. However, these transfer methods require substantial amounts of training data (more than 10B tokens), and the resulting hybrid models also exhibit poor long-context performance, which is the scenario where hybrid models enjoy significant inference speedups over Transformer-based models. In this paper, we present HALO (Hybrid Attention via Layer Optimization), a pipeline for distilling Transformer models into RNN-attention hybrid models. We then present HypeNet, a hybrid architecture with superior length generalization enabled by a novel position encoding scheme (named HyPE) and various architectural modifications. We convert the Qwen3 series into HypeNet using HALO, achieving performance comparable to the original Transformer models while enjoying superior long-context performance and efficiency. The conversion requires just 2.3B tokens, less than 0.01% of their pre-training data.

## Follow-Up Questions

1. HALO converts a pre-trained Transformer into a hybrid RNN-attention model using only 2.3B tokens — less than 0.01% of original pretraining data. Why is such efficient conversion possible, and what knowledge in the attention weights is being preserved versus discarded during the transfer to recurrent layers?

2. The paper identifies "poor long-context performance" as a key weakness of prior hybrid model conversion methods. Why would converting attention layers to RNNs specifically hurt long-context performance, and what does HypeNet's novel position encoding (HyPE) do differently to address this?

3. The paper frames the adoption of hybrid models as "hindered by the prohibitive cost of large-scale pre-training from scratch." Is distillation from a pre-trained Transformer a complete solution to this problem, or are there capabilities that only emerge from pre-training natively as a hybrid model from the start?

4. HypeNet applies "various architectural modifications" beyond just position encoding. What types of modifications are typically necessary when converting Transformer blocks to recurrent blocks, and how do these interact with the behavior of the remaining softmax attention layers?

5. The HALO pipeline converts the Qwen3 series specifically. How model-specific is the distillation process — could HALO be applied to models with different architectures (e.g., different normalization schemes, attention variants, or token embedding approaches) without significant redesign?

6. Hybrid models enjoy "significant inference speedups over Transformer-based models" particularly for long contexts. At what context length does the crossover point occur where a hybrid model becomes faster than an equivalent Transformer, and how does this crossover scale with model size?

7. What are the key failure cases where a Transformer distilled into a hybrid model would be expected to underperform the original — for instance, are there task types where the recurrent state is fundamentally insufficient regardless of how well the distillation is done?

## Answers

**1.** Efficient conversion is possible because pre-trained Transformer attention weights have already learned to represent information about local context patterns, syntactic structure, and semantic relationships — much of which can be approximated by a recurrent state machine operating over the same token representations. The key insight is that softmax attention in the middle layers of a trained Transformer behaves somewhat like a selective memory mechanism that already compresses context into a fixed-dimensional representation at each step; an RNN can approximate this behavior with far less training than learning it from scratch. During transfer, the recurrent layers preserve: the input-output transformation behavior for typical (short-to-medium range) dependencies; the learned feature representations in the key, query, and value projections. What gets discarded: the exact long-range attention pattern that requires O(n^2) computation — specifically, attention patterns that span more than the recurrent state's effective compression horizon.

**2.** Converting attention layers to RNNs hurts long-context performance because the recurrent state has a fixed size that must compress the entire preceding context — as sequence length grows, the compression ratio increases and relevant information is increasingly lost. Prior conversion methods used standard positional encodings (like RoPE) designed for softmax attention, which implicitly assume that nearby positions are most relevant; these encodings are poorly suited for recurrent states where position information must be compressed differently. HyPE (HypeNet Position Encoding) addresses this by designing position encodings that work coherently with the recurrent state's compression properties, likely using position-relative encodings that allow the recurrent state to maintain accurate position information over very long sequences without the exponential decay of typical RNN positional signals.

**3.** Distillation from a pre-trained Transformer is not a complete solution because it is fundamentally constrained by what the teacher Transformer learned during pre-training. The hybrid model inherits the teacher's knowledge representation, which was shaped by softmax attention training dynamics — the hidden states encode information in ways optimized for attention-based retrieval, not for recurrent state compression. Native hybrid pre-training from scratch would allow the model's entire representation system to co-evolve with the recurrent layers, potentially learning more efficient compressed representations. However, for most practical tasks, the 2.3B-token conversion is likely sufficient because the pre-trained representations are already general enough to be repurposed by the recurrent layers.

**4.** Common architectural modifications needed when converting Transformer blocks to recurrent blocks include: adjusting layer normalization placement (recurrent state updates interact differently with normalization than attention outputs); modifying the gating mechanisms to control information flow into and out of the recurrent state (which has no direct analog in standard attention blocks); adjusting the intermediate projection dimensions (recurrent architectures typically use different width ratios than attention blocks for similar computational cost); and ensuring compatibility between the recurrent state's hidden dimension and the residual stream dimensions of the remaining softmax attention layers, which must continue to read from and write to the same residual stream.

**5.** The HALO pipeline is moderately model-specific. The core distillation objective (minimize the divergence between teacher attention outputs and student recurrent outputs) is general, but the implementation details depend on the target model's architecture. Models with different normalization schemes (e.g., RMSNorm vs. LayerNorm) require adjusted normalization placement in the converted blocks. Models with different attention variants (GQA, MHA, MLA) require different mapping strategies for key, query, and value projections to the recurrent state. However, the HALO framework's general approach of progressive layer conversion with distillation objectives is transferable; what changes between models is the specific mapping and initialization scheme for each block type, not the overall pipeline structure.

**6.** The crossover point where hybrid models become faster than equivalent Transformers depends on the recurrent-to-attention layer ratio and context length. For a model with ~75% recurrent and ~25% attention layers, the crossover typically occurs around 2,000-4,000 tokens — below this, softmax attention's highly optimized CUDA kernels dominate, and above this, the O(n) scaling of the recurrent layers provides increasing advantage as context grows. This crossover scales with model size primarily through the batch size dimension: larger models typically operate at smaller batch sizes for memory constraints, which reduces the parallel advantage of attention and lowers the crossover threshold. At 100K+ token contexts, hybrid models are typically 5-10x faster than pure Transformers, which is the regime where their inference advantage is most compelling.

**7.** Key failure cases where distilled hybrid models underperform the original Transformer include: tasks requiring precise retrieval of specific information from very long sequences (e.g., "what was the exact value mentioned on page 3 of this 100-page document"), where the recurrent state's lossy compression of early context makes accurate retrieval unreliable; tasks requiring exact copying or verbatim reproduction of content from long input contexts, which requires exact memory of input tokens rather than compressed semantic representations; and tasks where the attention pattern the original Transformer learned has a distinctive non-local structure (e.g., attending specifically to position 0 for instruction recall, or attending to specific structured tokens like separators) that the recurrent state cannot replicate with the same precision. These are also the exact tasks where testing recurrent vs. attention models reveals fundamental capability differences, so distilled hybrid models should be validated specifically on long-range retrieval benchmarks.
