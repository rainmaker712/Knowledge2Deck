[Learning Facts at Scale with Active Reading](https://arxiv.org/abs/2508.09494)

Authors: Jessy Lin, Vincent-Pierre Berges, Xilun Chen, Wen-Tau Yih, Gargi Ghosh, Barlas Oğuz

> 언어 모델이 스스로 학습 전략을 생성하고 적용하여 사실 지식을 파라미터에 내재화하는 Active Reading 프레임워크. 동일한 커버리지 하에서 전략적 다양성이 성능을 좌우한다는 핵심 통찰을 기반으로, WikiExpert-8B는 1T 합성 토큰으로 236B 파라미터 모델을 사실 벤치마크에서 압도한다.

- **자기 지시적 전략 생성(Self-Directed Strategy Generation)**: 모델이 소스 문서를 주어받아 스스로 다양한 학습 전략(패러프레이징, QA 생성, 지식 연결, 유추 추론 등)을 제안하고 이를 적용해 합성 학습 데이터를 생성한다. Task-agnostic(범용)과 task-specific(다운스트림 태스크 명세 필요, 더 높은 성능) 두 변형이 존재한다. SimpleWikiQA task-specific: 66.25% vs 7.42% baseline; FinanceBench info-subset: 66.18% vs 3.93% baseline (전체 벤치마크 기준 논문 원문 보고: +313%, +160% relative).
- **지식 내재화의 스케일링 장벽 돌파**: 패러프레이징과 단독 QA 생성은 4B 생성 단어 이전에 고원에 도달하는 반면, Active Reading은 4B까지 지속적 향상을 보여 더 높은 스케일링 상한을 시사한다. WikiExpert-8B(Wikipedia 1T 합성 토큰)는 SimpleQA에서 23.5%로 DeepSeekV2 236B(10.2%)·Llama 3.1 405B(17.1%)를 능가한다 (단, DeepSeekV3 671B는 24.9%로 WikiExpert보다 높음). NaturalQuestions 31.2%, TriviaQA 68.5%도 기록.
- **다양성이 커버리지보다 중요하다 (커버리지 통제 실험)**: 방법 간 사실 커버리지를 동일하게 통제한 실험에서 Self-BLEU 다양성 점수만이 성능 차이를 예측한다 — 이것이 논문의 핵심 이론적 주장이다. 동일 사실에 대해 다중 인코딩 경로(이질적 형식)를 파라미터에 각인시키는 것이 메커니즘이며, 단순 반복(패러프레이징)보다 관계적/구조적 전략(지식 연결, 유추)이 한계 이득이 더 크다.
- **전문화 비용과 사전학습 혼합 제약**: WikiExpert 특화 후 Table 4에서 일반 능력 저하가 관측된다(MMLU 66.4%→65.5%, GSM8K 54.4%→48.6%, MBPP 48.0%→39.4%). 또한 사전학습 데이터 혼합이 1T 스케일 학습에 필수적이지만 메커니즘은 미설명. 현대적 RAG 시스템과의 직접 비교는 논문에 포함되지 않으며, "gold-context oracle"만이 상한 기준으로 사용된다(SMT 260330이 RAG 직접 비교를 수행하며 Active Reading이 RAG에 미치지 못함을 확인).
- **컬렉션 내 위치 — 전략적 다양성 축의 기반 논문**: Synthetic Mixed Training(2603.23562)이 Active Reading을 4가지 기준선 중 하나로 사용하며 이를 기반으로 발전한다. "Demystifying Synthetic Data"의 다양성-효율 분석, Megadocs의 구조적 다양성과 대비하여 *전략적 다양성이 사실 지식 스케일링의 주요 인과 인자임을 처음으로 분리 검증*한 논문으로 컬렉션에서 위치를 가진다.

## Follow-Up Questions

1. Active Reading은 "전략 다양성"이 스케일링의 핵심이라고 주장하고, Megadocs는 "구조적 다양성"(멀티 재작성을 하나의 시퀀스에 조합)이 데이터 효율성의 핵심이라고 본다. 이 두 접근법이 직교하는 메커니즘을 포착하는가? Active Reading 전략으로 생성된 재작성을 Megadocs 스타일로 구성하면 이득이 가산적인가?
2. Coverage는 동일한데 Active Reading이 Self-BLEU가 낮다(더 다양하다)는 것이 관찰되었다. 이 다양성이 지식 보유를 향상시키는 정확한 분산 메커니즘은 무엇인가 — n-gram 신규성, 통사적 변형, 의미적 재구성 중 어느 것이 핵심인가? 더 다양할수록 항상 좋은가, 아니면 포화점이 있는가?
3. WikiExpert-8B의 학습 소스(Wikipedia)와 주요 평가 벤치마크(SimpleQA, NaturalQuestions, TriviaQA)가 모두 Wikipedia에서 파생된다. 1T 토큰의 합성 재작성이 소스를 체계적으로 커버한다면, 측정하는 것이 지식 일반화인가, 아니면 Wikipedia 지식 분포에 대한 정교한 암기인가?
4. 커버리지가 동일한데 Active Reading이 더 잘 작동한다면, 이것이 동일 사실에 대해 다중 인코딩 경로를 생성하는 것이 핵심이라는 의미인가? 더 많은 전략이 항상 더 나은가, 아니면 일부 전략 유형이 다른 것보다 한계 이득이 높은가?
5. Task-specific 변형이 task-agnostic보다 일관되게 우월한데, WikiExpert-8B는 다양한 이기종 벤치마크에서 평가된다. 광범위하거나 복합적인 태스크 설명(예: "모든 사실적 질문에 답하도록 준비")을 사용하면 task-specific 이점의 대부분을 유지할 수 있는가?
6. Thinking Augmented Pre-Training(TPT)은 "파인만 기법" 프롬프트로 어려운 토큰 앞에 생각 궤적을 삽입하고, Active Reading은 다양한 전략으로 전체 문서를 재구성한다. Thinking to Recall이 추론의 "계산 버퍼"와 "사실적 프라이밍" 역할을 보여준다면, Active Reading의 사실 벤치마크 우월성은 더 다양한 연상 다리에서 오는 것인가, 아니면 완전히 다른 메커니즘에서 오는가?
7. Active Reading은 사전학습 데이터와의 혼합이 스케일링에 필수적이라고 언급하지만, 왜 혼합이 필요한지에 대한 메커니즘은 불명확하다고 인정한다. 합성 전용 학습이 실패하는 구체적 실패 모드는 무엇이며, 이것이 합성 데이터의 분포적 결함인가 아니면 언어 모델링 능력의 퇴화인가?

## Answers

**1.** Active Reading과 Megadocs는 합성 데이터의 서로 다른 축을 최적화한다. Active Reading은 *생성 전략의 다양성*을 통해 동일 사실에 대해 패러프레이징, QA, 지식 연결, 유추 추론 등 질적으로 이질적인 텍스트를 만들어 모델이 사실을 다양한 인코딩 경로로 접하게 한다. 반면 Megadocs는 *구조적 조직화*를 통해 동일 소스의 여러 재작성을 단일 긴 시퀀스로 배치하여, 모델이 하나의 컨텍스트 윈도우 안에서 동일 의미의 다양한 표현을 비교 대조하며 의미적 불변성을 학습하도록 강제한다. Active Reading이 "무엇을 생성하는가"의 다양성을 극대화한다면, Megadocs는 "어떻게 배치하는가"의 구조를 최적화하는 것이므로 두 메커니즘은 원칙적으로 직교한다. Active Reading의 다양한 전략 출력물을 Megadocs 형식으로 하나의 시퀀스에 연결하면 전략 다양성이 제공하는 다중 인코딩 이점과 구조적 배치가 제공하는 장거리 의미 비교 이점이 가산적으로 작동할 가능성이 높으나, 두 방법 모두 다양성 증가를 통해 수확 체감을 완화한다는 점에서 일부 중복이 불가피하다.

**2.** Active Reading의 다양성이 지식 보유를 향상시키는 핵심 메커니즘은 n-gram 수준의 단순 변형이 아니라, 동일 사실에 대한 *의미적 재구성의 다양성*이다. 커버리지가 동일한데 성능이 다르다는 실험 결과가 이를 직접 뒷받침한다: 동일한 사실이라도 QA 형식으로 한 번, 유추 형식으로 한 번 접한 모델은 단순 패러프레이징으로 두 번 접한 모델보다 더 강건하게 해당 사실을 인코딩한다. 포화점에 관해서는 전략 유형별로 고원 시점이 비대칭적이다 — 패러프레이징과 QA는 비교적 일찍 포화되는 반면, 지식 연결과 유추 추론은 더 오래 이점을 유지한다. 이는 총 다양성 자체보다 질적 이질성의 유지가 더 중요함을 시사하며, 전략 구성에서 관계적/구조적 전략에 더 많은 비중을 할당하는 것이 효율적임을 의미한다.

**3.** 이 우려는 상당히 정당하다. Wikipedia는 NaturalQuestions, TriviaQA, SimpleQA 등 주요 사실 벤치마크의 표준 지식 소스이므로, WikiExpert-8B의 성능 향상이 새로운 지식의 일반화 능력을 반영하는지, 아니면 Wikipedia 사실 분포에 대한 정교한 과적합을 반영하는지 구분하기 어렵다. WikiExpert-8B가 SimpleQA에서 DeepSeekV2 236B(10.2%)를 압도하면서도 NaturalQuestions에서 Qwen2.5-72B(33.2%)에 미치지 못하는 비대칭적 결과는, 모델이 Wikipedia 분포를 잘 암기했으나 질문 형식이나 지식 조합 방식이 달라지면 이점이 줄어들 수 있음을 시사한다. 진정한 일반화를 입증하려면 Wikipedia와 독립적인 지식 소스에 대한 평가가 필요하며, FinanceBench에서의 +160% 결과가 부분적으로 이를 보완하지만 소스 독립성이 완전하지 않다.

**4.** 논문의 스케일링 실험은 더 많은 전략이 항상 단조적으로 더 나은 것은 아니며, 전략 유형별 한계 이득이 상이함을 보여준다. 패러프레이징과 QA 전략은 비교적 일찍 고원에 도달하는 반면, 지식 연결과 유추 추론 전략은 더 오래 이점을 유지한다. 이는 패러프레이징과 QA가 사실의 표면적 재표현에 해당하여 비교적 빨리 포화되는 반면, 지식 연결과 유추는 사실 간 관계를 새로운 구조로 재조직하여 더 깊은 수준의 인코딩 다양성을 제공하기 때문으로 해석된다. 실용적으로는 제한된 합성 데이터 예산 내에서 최대 효과를 얻으려면 전략 유형의 수를 늘리되 특히 관계적/구조적 전략에 더 많은 비중을 할당하는 것이 효율적이다.

**5.** WikiExpert-8B가 다양한 벤치마크에서 평가되므로 실질적으로 이 질문을 간접 검증한다. Task-specific이 task-agnostic보다 우월한 이유는, 태스크 설명이 전략 생성 단계에서 다운스트림에 직접 유용한 형식을 우선적으로 생산하도록 유도하기 때문이다. 광범위한 태스크 설명은 특정 태스크에 대한 최적 적합도는 떨어지겠지만, 여러 벤치마크에 걸친 평균 성능은 task-agnostic보다 높을 가능성이 있다. 충분한 스케일(1T 토큰)에서 전략 다양성 자체가 특정 태스크 최적화를 부분적으로 보상할 수 있음을 WikiExpert-8B의 크로스벤치마크 성능이 시사한다.

**6.** TPT, Thinking to Recall, Active Reading은 모두 사실 회상을 개선하지만 작동 메커니즘이 구별된다. TPT는 어려운 토큰 직전에 사고 궤적을 삽입하는 *토큰 수준 스캐폴딩*이고, Thinking to Recall이 밝힌 대로 이 이점은 계산 버퍼와 사실적 프라이밍 두 가지에서 온다. 반면 Active Reading은 *문서 수준*에서 동일 사실을 질적으로 이질적인 형식으로 재구성하여 파라미터 공간 내 접근 경로를 다중화한다. 사실 벤치마크에서 Active Reading의 우월성은 Thinking to Recall이 말하는 "사실적 프라이밍"의 학습 시점 버전에 해당한다: 추론 시 연상 다리를 활성화하는 것이 아니라, 학습 시 이미 다양한 연상 경로를 파라미터에 각인시켜 추론 시 단순 질의만으로도 사실에 도달할 수 있게 한다. TPT가 추론 시 사고 궤적에 의존하는 반면 Active Reading은 그런 의존 없이 파라미터 자체에 다중 접근 경로를 내재화하므로, 추론 시 추가 토큰 비용 없이 사실 회상이 가능하다는 실용적 차별점이 존재한다.

**7.** Active Reading 논문이 사전학습 데이터 혼합의 필요성을 인정하면서도 메커니즘을 설명하지 못한다는 점은 합성 데이터 연구의 핵심 미해결 과제를 드러낸다. 합성 전용 학습이 실패하는 모드는 두 가지로 추정된다. 첫째, *분포적 결함*: 합성 데이터는 LLM 생성기의 출력 분포를 반영하므로 실제 텍스트의 저빈도 패턴이 체계적으로 과소 대표되어 모델의 언어적 범위가 축소된다. 둘째, *언어 모델링 능력의 퇴화*: 합성 텍스트는 생성기 모델의 편향을 상속하여 문체적 단조로움과 특정 구조의 과다 반복을 초래하고, 이는 일반 목적 언어 모델링에 해롭다. Megadocs가 합성 비율 0.75~0.9까지 허용한다는 결과와 대비하면, Active Reading의 혼합 필요성은 전략적 재작성이 원본 텍스트의 분포적 특성을 충분히 보존하지 못함을 시사하며, 이는 Megadocs가 원본을 메가독 내에 반드시 포함시키는 설계와 대조적이다.
